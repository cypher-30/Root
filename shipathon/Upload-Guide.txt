-----------------------
1. RevenueCat purchase requirement: this is the biggest risk. The rules say a
   project "must ... use the RevenueCat SDK to power at least one in-app or web
   purchase". Root has RevenueCat integrated, but by design it sells nothing until
   a native-reviewed premium pack exists. That means no purchase can be shown
   today. The rules also say Next Gen is judged on the video and the repository,
   so this may be fine. Ask in the Shipaton Discord (or email the organizers)
   before the deadline rather than guessing. The notes for the judges already
   explain this honestly.
2. Repository link: main was fast-forwarded to the current build (91f0b5f),
   so the answers link the repository root: https://github.com/cypher-30/Root
   The MIT license is detected by GitHub (checked).
3. The story is about 1,000 words. Devpost showed no limit in the form you
   copied; if it complains, cut "Accomplishments" first.
